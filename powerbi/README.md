# Power BI portfolio risk dashboard

Power BI Desktop is Windows-only, so the `.pbix` file itself is not generated by the pipeline.
Instead the pipeline produces everything the report needs, and `reports/dashboard.html` is a
runnable twin with the same pages and measures (open it in any browser).

| File | Purpose |
|---|---|
| `data/*.parquet` (+ `.csv` for small tables) | Star schema, marts and model outputs - written by `loanlens report` |
| `load_loanlens.pq` | Power Query template that loads the whole folder |
| `loanlens_measures.dax` | Every measure used on the pages below, plus the relationships |
| `loanlens_theme.json` | Theme with the validated, colour-blind-safe palette |

For live, loan-level detail connect Power BI to PostgreSQL instead (`docker compose up postgres`
then `loanlens publish-postgres`; Get Data > PostgreSQL, database `loanlens`).

## Build steps (about 30 minutes)

1. `loanlens all` (or `make all`) so `powerbi/data` is populated.
2. Power BI Desktop > Get Data > Parquet (or paste `load_loanlens.pq`), load the tables.
3. Model view: create the relationships listed at the top of `loanlens_measures.dax`; mark
   `dim_date` as the date table (column `month`).
4. Create a `_Measures` table and paste the measures. View > Themes > Browse > `loanlens_theme.json`.
5. Build the five pages below. Add slicers for `dim_date[year]`, `dim_geography[census_region]`
   and `dim_loan[fico_band]` in one row at the top of each page (sync slicers across pages).

## Pages

**1. Portfolio overview**
- Cards: Outstanding Balance (Latest), Active Loans (Latest), DQ30+ Rate, Serious DQ Rate (Latest)
  with Serious DQ Rate vs 12M Ago (bps) as the subtitle, Expected Loss 12M, Stress Loss 99th Percentile.
- Line: Serious DQ Rate (90+) and DQ30+ Rate by `dim_date[month]`.
- Area: Outstanding Balance by month. Line: CPR; separate line chart: CDR (never one chart with two axes).

**2. Vintage curves**
- Line: Cumulative Default Rate, x = `mart_vintage_curves[months_since_first_payment]`, legend =
  `vintage_year` (filter to 3-5 vintages, e.g. 2003 / 2007 / 2016, and grey the others).
- Line: Cumulative Loss Rate, same axes. Table: `mart_loss_by_vintage`.

**3. Roll rates**
- Matrix: rows `from_state`, columns `to_state`, value Roll Rate (Pooled), conditional-format
  background with the sequential blue scale; filter to the last 12 months.
- Line: Current to 30; separate line: 30 to 60, 60 to 90 and 30-Day Cure Rate.

**4. Risk segments**
- Matrix heatmap: rows `fico_band`, columns `ltv_band`, value Expected Loss Rate.
- Filled map (or shape map) of Expected Loss Rate by `state_code`; bar: DQ30+ Rate (Balance) by `fico_band`.
- Table: `rpt_risk_segments_el` sorted by Expected Loss 12M.

**5. Stress test**
- Cards: Expected Stress Loss Rate, Stress Loss 99th Percentile, Expected Shortfall 99, Severely Adverse Loss Rate.
- Histogram (column chart on binned `loss_rate`) of `rpt_stress_loss_distribution`.
- Line: `stress_paths[value]` by `month`, legend `path`, one visual per `measure`.
- Scatter: `unemployment_rise` vs `loss_rate`, colour saturation = `hpi_trough_change`.
- Line: `backtest_monthly` actual vs projected defaults.

Optional page 6, **Data quality**: DQ Pass Rate card, `mart_data_quality` by suite, `mart_ingest_history` table.
